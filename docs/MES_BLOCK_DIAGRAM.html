Production and Quality Control Path

The main manufacturing path is a controlled sequence. Each stage produces records used by the next stage.

Production sequenceOrder to released pack
1. Supplier ingestValidate manifest and create cell inventory.
→
2. Create orderSelect product and quantity; check material.
→
3. Reserve cellsLink reserved cells to order and battery.
→
4. Build twinAssign cells, BMS and BMU by scan.
→
5. Cell QAOCV/IR, grade and damage history.
6. Match modulesBalance cells into module slots.
→
7. Weld + module QCLaser weld, busbar, voltage, insulation.
→
8. Pack assemblyEnclosure, harness and controllers.
→
9. Final testPack IR, Hi-Pot, dynamic load, telemetry.
→
10. Final QCRelease or quarantine; create QR passport.
↓ every write carries identity, timestamp, status, and audit event
Workflow state and quality gatesControls progression
Battery state machineCELL_IDENTIFICATION → CELL_TESTING → GRADING → DAMAGE_HISTORY → MODULE_ASSEMBLY → LASER_WELDING → MODULE_QC → BATTERY_ASSEMBLY → BMS_INTEGRATION → FINAL_TESTING → FINAL_QC → COMPLETED.
Prerequisite checksRequired cells, required BMS/BMU, module count, test result, QC result, and no open quarantine.
Exception pathFailure sends item to quarantine. Supervisor bypass requires a reason and audit record.
Release decisionOnly a passed final QC should set FINISHED, create release QR, and update order completion.
1Important control boundary: the state machine must be enforced in the server/RPC layer, not only by button visibility. A failed write should roll back the whole stage transaction.
Machine-assisted operationsPhysical equipment feedback
OCV / IR testerCell electrical measurements.
Laser welderPower, time, pull-force cycle.
BMS / CAN testerTelemetry, sensors, frame health.
Final dynamic testerPack-level load and Hi-Pot.
Primary flow: controlled manufacturing sequence2 / 4

Inventory, QR Passport, and Traceability

The warehouse and genealogy views connect physical serial numbers to a released battery record.

Warehouse inventory domainSeparate stock views, shared status model
Cell inventorySupplier barcode, internal serial, measurements, grade, pallet/box, allocation.
BMS inventorySerial, model, supplier, firmware, hardware, protocol, test and status.
BMU inventorySerial, model, manufacturer, protocol, test and status.
Module inventorySerial, cells, matching score, welding, QC, parent battery.
Battery inventoryPack serial, product, modules, BMS, BMU, step, progress, release.
↓ scan / QR / universal identifier
Battery QR passportGenerated when final QC passes
Battery labelPack serial, product, release date/status, stable payload.
BMS labelBMS serial, model, protocol, parent battery context.
BMU labelBMU serial, model, protocol, parent battery context.
Module labelsModule serial, module position, parent battery context.
↓ identifier lookup
Universal genealogy treeBidirectional traceability
Forward traceSupplier batch → cell → module → battery → BMS/BMU → final QC → release → dispatch.
Reverse traceScan cell, module, BMS or BMU to find its parent battery, tests, operators and audit events.
Detail panelSerial, status, measurement values, timestamps, machine identity, disposition and notes.
Quarantine and dispositionSafety barrier
Detect defectManual or automated failure creates open quarantine.
IsolateSet component status QUARANTINED and prevent allocation.
DispositionRelease approved, rework, or scrap with signed notes.
AuditRecord actor, reason, old/new state, time, and resolution.
2Integrity rule: BMS and BMU must link symmetrically to both their own inventory records and the battery record. Quarantine must support both controller types.

Backend control boundaryserver/routes.ts + state machine
